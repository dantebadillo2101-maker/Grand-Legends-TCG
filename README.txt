Grand Legends TCG — SET 06: EVOLUTION OF HOLE

Integración sobre la versión Web Oficial.

Incluye:
- 6 expansiones activas.
- Set 06 con 6 líderes (E01-E06) + 54 cartas (E07-E60).
- Mecánica Evolución Alarmante, una vez por turno.
- Invocación gratuita ignorando coste.
- Al usar Evolución Alarmante, Sombras del Infierno queda bloqueada para el resto de la partida del jugador.
- E36 solo puede invocarse mediante Evolución.
- Filtro de líderes Set 06.
- Filtro del constructor Set 06.
- Catálogo Set 06.
- Estado visual de Evolución/Sombras durante la batalla.
- IA con evaluación básica de Evolución Alarmante.

No se reemplaza la identidad visual del proyecto: se mantiene el HTML/CSS oficial y se añaden únicamente los elementos necesarios.

Nota: algunas habilidades complejas de Set 06 se implementan como versiones funcionales simplificadas (por ejemplo, scry/reordenamiento se registra en el log en vez de abrir un selector completo).
